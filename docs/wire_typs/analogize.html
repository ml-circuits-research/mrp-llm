All wire types

analogize

Analogy searches injective mappings from entities in source features to entities in target features. It may transfer explicit extra features as untested hypotheses; it does not establish causal or logical equivalence. Trusted system/tool circuits can use this operation; model-authored declarative input cannot invoke it directly.

SOP syntax: @id type, exactly two leading spaces on each field line, $id for a computed value, ~id for a declaration handle, and ?x for a local logic variable or an output name. Atoms use [not ]predicate term1 [term2 [term3 [term4]]] with one to four whitespace-separated terms; lowercase predicate names, canonical symbols, JSON-quoted strings or safe integers. Parenthesized predicate(arg, …) and comma-separated arguments are not executable syntax.

Fields and inputs

KeywordCardinalityAccepted value, default and effect
sourceAt most once; requiredOne $trace, ~trace, $fact, ~fact, $query, or packed $array. Extracts trace features, fact atoms or query atoms as source structure. ~query is not accepted.
targetAt most once; requiredSame accepted feature-producing values as source. Mapping considers concrete string entities appearing in the target atoms; more source entities than target entities gives no mapping.
transferAt most once; optionalOne optional $hypothesis, ~hypothesis, trace/fact/query value or packed array. Hypothesis assumptions or other supported features are projected through a completed entity mapping; default empty.
reasoningAt most once; optionalA strategy name (plain token), default host policy.reasoningStrategy (reference by default). Built-ins: reference (the js-reference oracle; js-reference and js-oracle are the same route) and the deprecated advanced (the oracle plus optional external backends for deduction and numeric constraints). The host may restrict allowed strategies.
policyAt most once; optionalOne $policy value or ~policy declaration handle. It must lower to a policy object; each specified positive integer budget caps the corresponding host budget by min(host, wire). No policy reference means host limits alone.
outputRepeatable; optionalRepeatable ?name [one|many|rows|count|status] declaration, default one. Each output becomes a deferred $name value if bound; names must be unique and cannot collide with explicit wires. status binds result status even for incomplete results. Other modes require completeness; unusable/unselected modes become blocked, not arbitrary first answers.
afterRepeatable; optionalRepeatable $wire value-dependency reference. Orders execution after that producer; it does not alter inputs, proofs or output. A ~definition handle is graph-checked but is not a value-ordering dependency.

Only source/target features count toward matching: same predicate, arity and polarity after a one-to-one entity mapping. Extra transfer atoms are proposed only if all their symbolic entities can be mapped (numeric terms are retained); they do not become facts.

Result and limits

Returns status approximate (unknown when no mapping exists) with guarantee approximate and ranked mappings with matched edge counts, scores and optional untested proposed hypotheses. Output one/many/rows projects mappings; count unsupported; status projects approximate or unknown. No assertion.

All operations use bounded search (host defaults include maxNodes 5000, maxDepth 8, maxCandidates 512, timeoutMs 3000); a ~policy can only tighten configured limits. The result records completeness and epistemic status relative to supplied finite inputs and the visible memory view, never calibrated truth probability. No operation here writes to the repository; after is only scheduling. Entity mapping search is combinatorial and may truncate. It requires literal matching predicate names/polarities and does not discover semantic synonyms or unrestricted analogical relations.

Executable examples

Transfer a possible condition

@old trace
  feature linked pump1 valve1
@new trace
  feature linked pump2 valve2
@possible hypothesis
  holds faulty valve1
@analogy analogize
  source ~old
  target ~new
  transfer ~possible

A matching structural mapping can propose faulty valve2 as an untested hypothesis; it does not establish a fault.

Map two relations

@sourceCase trace
  feature owns alice rover
  feature drives alice rover
@targetCase trace
  feature owns bob cart
  feature drives bob cart
@compare analogize
  source ~sourceCase
  target ~targetCase
  output ?matches many

The mapping alice→bob, rover→cart matches both source relations and appears among candidates if search completes.

Valid, but not evidence

@sourceCase trace
  feature linked a b
@targetCase trace
  feature unrelated c d
@weak analogize
  source ~sourceCase
  target ~targetCase

This runs, but it is unsafe to interpret as evidence of a shared mechanism: no identical-predicate relation matches, so the operation returns no mapping.

Invalid: unsupported output mode

@sourceCase trace
  feature linked a b
@targetCase trace
  feature linked c d
@bad analogize
  source ~sourceCase
  target ~targetCase
  output ?size count

The parser accepts the output declaration, but the runtime rejects it with count output requires a count query: an analogy result has mappings, not a count. Use many or rows to project the mappings.
