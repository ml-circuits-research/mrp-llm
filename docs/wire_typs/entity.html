entity

A reviewed identity of a base memory: its class, one label per language and any number of aliases through which mentions resolve to the symbol. A class is an entity of kind class; there is no separate concept wire.

Status and author: Knowledge wire of a base memory, written by a person, a model or a mapping tool (for example tools/world-kb for the Wikidata world). The small model never authors it, and a user document cannot approve a new identity. An unknown or ambiguous mention is resolved or clarified, never invented as an entity.

Accepted fields

Single means at most once, repeatable means zero or more, and required means at least once. Other field names are rejected (unknown_field). The table is generated from the grammar in sop/knowledge/grammar.mjs.

FieldCardinalityAccepted values and behavior
kindAt most once; optionalThe class of the entity: a class symbol declared in this memory or its imports (entity_kind_unknown). Absent means the root class entity. The value class makes the wire itself a class. Further memberships are is_a facts.
labelRepeatable; at least onelabel en "text": one display form per language, and the language is en (label_duplicate_language; any other language is non_english_knowledge); mentions resolve through it (entity_without_label when none).
aliasRepeatable; optionalalias en "text": any further surface form (an inflected form, an abbreviation) that mentions resolve through.
domainAt most once; optionalA lowercase symbol that scopes the identity (so homonyms of different domains do not collide).
notabilityAt most once; optionalAn integer the memory supplies (for example the number of Wikipedia editions). It only decides, at build time, which namesake keeps the plain label (label_collision otherwise).
sourceAt most once; optionalText: where the identity comes from.

What it is for and how to write it

The linker looks a mention up in the labels and aliases of the entities of the session's base memory (exact first, then accent-folded), restricted by the class an argument asks for. Class membership comes from kind and from is_a facts closed over is_a between classes. The classes themselves are entities of kind class; core-min declares class entity person organization place occupation property unit.

Examples

@person entity
  kind class
  label en "person"
@place entity
  kind class
  label en "place"
@ada_lovelace entity
  kind person
  label en "Ada Lovelace"
  alias en "Ada, Countess of Lovelace"
  notability 90

Invalid: a kind the memory does not declare

@ada entity
  kind person
  label en "Ada"

Invalid: no label

@ada entity
  kind entity

Common mistakes

  1. Using an undeclared kind: declare the class first.
  2. Two entities with the same plain label and no notability: the linker will ask, or the build reports label_collision.
  3. Writing an alias for a predicate: relation phrases are lexemes.
  4. Declaring a class as a separate wire type: use kind class.
