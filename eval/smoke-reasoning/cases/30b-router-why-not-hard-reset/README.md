# 30b-router-why-not-hard-reset

**Reasoning feature exercised:** Mode of work: why a step is not allowed (blocked by a named norm, not a bare no_plan).

**Expected answer:** status blocked, blocked_by [no_hard_reset_in_hours].

**Needs:** why_not, plan, method, norms_hard, blocked_info.
