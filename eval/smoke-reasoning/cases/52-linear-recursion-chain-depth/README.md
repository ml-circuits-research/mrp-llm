Linear recursion over a chain of 110 edges (the derivation is 110 rounds deep) with a back edge that makes a cycle and a second chain the walk never reaches. A recursive CTE runs the whole walk as one statement and a UNION keeps the cycle finite; the unit tests of sql-sqlite run the same program at depth 1,000 and compare with the oracle at smaller sizes. Expected rows computed from the generator. Feature: linear recursion, depth, cycle safety.
